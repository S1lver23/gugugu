# 對外展示前安全檢查（2026-10-15）

## 已發現與修正

- 高風險：Apache 允許下載 `.git/config`、`.env.example`、資料庫 SQL 與測試程式。已封鎖隱藏路徑、內部目錄、備份及除錯檔案，停用 `stock_tool.php` 對外存取。實際 HTTP 測試皆 403，登入頁仍 200。
- 高風險：API 綁定所有網卡，且無條件信任一層代理，可透過轉送 IP 規避限流。改成預設僅監聽 127.0.0.1、預設不信任代理標頭。受控本機反向代理部署時才可明確配置 TRUST_PROXY=loopback，且代理必須覆寫外來轉送標頭。
- 加入全 API 每 IP 每分鐘 180 次、外部行情查詢每分鐘 30 次限制；既有登入 15 分鐘 10 次等細部限制保留。限流資料有清理及數量上限，避免記憶體持續成長。
- 限制額外追蹤股票最多 200 檔，MIS 外部請求 10 秒及 2 MB 上限。報價失敗數值明確為 0，記錄原因；不偽造資料。
- 密碼雜湊及比對改為非同步；限制 bcrypt 密碼最大 UTF-8 72 位元組，降低大型輸入與同步工作阻塞。
- 跨站寫入來源檢查、避免 API 錯誤堆疊外洩、補上防框架嵌入與 nosniff 安全標頭。
- 股票名稱與部分財報欄位加入 HTML 跳脫；提醒使用者輸入本已有跳脫及權限檢查。此項為重點路徑修補，未宣稱全面消除所有前端 XSS。

## 驗證證據

- 敏感路徑 403；正常登入頁 200。
- 未登入存取收藏、提醒及 CSRF API：401。
- 非允許網站 Origin 發起登入：403。
- 畸形 JSON：400，中文一般錯誤，不含堆疊。
- 改換 X-Forwarded-For 仍會觸發登入 429。
- 實際服務僅監聽 127.0.0.1:4000。
- /api/snapshot：200，資料結構正常。
- 自動化測試：9 項通過（一般測試 8 項，另行開啟會員隔離資料庫整合測試 1 項）。寄信測試攔截，不寄出真實郵件。
- npm audit --omit=dev：當次已知漏洞 0；不代表程式無漏洞。
- 修改的 JS/PHP 語法與資料 JSON 解析通過。

## 公開連線前仍需完成

1. 固定 HTTPS 公開入口、ALLOWED_ORIGINS、APP_URL、Secure Cookie 及可信代理設定。目前仍為本機模式，不應直接公開原始 XAMPP 根目錄（含 phpMyAdmin）。
2. MySQL 使用有限權限專用帳號；禁止公開 3306、Node 4000 及 phpMyAdmin。實際密碼不應出現在報告或 Git。
3. PHP 的財報／ETF 等讀取端點不經 Node 限流，公開入口需另加統一限流、同時請求上限或快取。此輪未完成全站壓力測試。
4. 現有 Node session 與限流存於記憶體；重啟會登出並清空限制。單筆電展覽可用，長期或多實例部署應更換共享持久儲存。
5. 實際公網網址確定後，從手機行動網路驗證 HTTPS、登入、跨帳號隔離、重設信與敏感路徑。測試備份還原，展覽可用展示專用資料。

本檢查是程式與本機 HTTP 安全檢查，不是第三方滲透測試，無法保證抵禦所有攻擊或大規模 DDoS。
